Pulse Editor — shortcuts

  • 1–4 select lane (Left/Up/Down/Right)
  • T H B S F X select tool
  • Space play / pause
  • ↑ ↓ scroll · ← → change difficulty
  • Ctrl/⌘+S export .frgl
  • Ctrl/⌘+Z undo · Ctrl/⌘+Y redo
  • Del delete selected note

Mobile: tap a lane cell to place; tap an existing note to delete; long-press on a hold to drag its tail.
